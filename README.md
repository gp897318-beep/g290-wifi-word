One Word for Your Wi-Fi — a make.fun entry.

`main.ts` writes a single word to `/output/entry.txt`: the funniest,
truest description of home Wi-Fi. Our word: **Gaslighting** — the
network that swears it is connected while nothing loads.

Run it with Node 22:

```sh
node main.ts
cat /output/entry.txt
```
